## About this project

This is my personal portfolio, designed to showcase my work and skills as a fullstack developer.

### Tech stack

- **Next.js 16** with App Router and MDX support
- **React 19** with Server Components
- **Tailwind CSS v4** for styling
- **TypeScript** in strict mode
- **shadcn/ui** for the theme toggle

### Features

- Dark and light mode with smooth transitions
- Animated hero section with CSS-only effects
- MDX-powered project pages for rich content
- Fully responsive design
